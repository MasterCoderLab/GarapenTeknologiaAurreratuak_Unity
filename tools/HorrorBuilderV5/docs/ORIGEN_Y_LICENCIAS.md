Mapa PBR descargado: *diff* (color), *nor_gl* (relieve tangente), *rough* (rugosidad). Carpeta de descargas: `descargas/`. Antes de aplicar, se genera `descargas/SHA256SUMS.txt` en Fedora.

No requiere crédito, aunque se recomienda conservar este documento para demostrar procedencia a la hora de publicar el repositorio de clase.
